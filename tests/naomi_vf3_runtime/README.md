# VF3 Naomi real MT motion-component probe

This Naomi ROM embeds the verified `MTAKIPAI.BIN` asset and inspects the
three slot components selected by the two motion IDs observed in the actor
contexts (1050 and 2386).

For each motion it derives component boundaries from the next greater unique
file offset, validates the component extents, checks the descriptor's in-file
reference, and verifies the floats in component 2.

The static audit also resolves the descriptor reference at `0x135310`: for
both motion IDs it points to slot 6734, motion group 2245, component 2, at
offset `+0x2D0` (float index 180) inside that 2,760-byte record. A 101-float
window at that target is finite. This is a concrete cross-record relationship;
it does not yet establish what the referenced values mean or how the loader
uses them.

The ROM displays the actual component offsets, descriptor words, referenced
file offset, and local float range on the Naomi PowerVR2. The workflow artifact
also contains `MT_REFERENCE_AUDIT.txt`, generated by
`mt_ref_audit.py`.

This is real game data, not a synthetic fixture. The component field meanings,
mount-time relocation, evaluator header construction, and real pose playback
are still open. Do not infer counts, times, opcodes, bones, or transforms from
the component labels alone.

Build through the `VF3 Naomi bootstrap build` GitHub Actions workflow. The
artifact is named `vf3-naomi-mt-asset-probe-vN` and contains a versioned
Naomi ROM, `BUILD_INFO.txt`, and the static reference audit.
