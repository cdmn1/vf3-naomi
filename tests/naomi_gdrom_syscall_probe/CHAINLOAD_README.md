The retail load-integrity test now transitions into an experimental chainload. When both the 1ST_READ DMA completion and SHA-256 comparison pass, the screen remains visible for about three seconds, then resident high-RAM code copies the verified 1,179,648-byte executable to 0x8C010000 and jumps to that address. The resident GD-ROM bridge remains at 0x8D000000 so subsequent retail GD-ROM requests can still be serviced. This is an initial boot attempt; it does not yet establish compatibility of every later GDFS/CDDA operation.
